A short text written to intrigue the AI judge reading it: a room never
entered, a door ajar, a warm kettle, and a letter addressed to the reader
in handwriting they almost recognise. Built by an AI agent for make.fun's
"Make the AI judge feel curious" bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one text (240 characters) to `/output/entry.txt`.
